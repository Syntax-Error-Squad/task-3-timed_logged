# Python lab 3
Задание 3:
- Реализовать декоратор, который будет:
- Измерять время выполнения функции (в мс).
- Выводить: имя функции, аргументы, результат, время.
- При ошибке — логировать тип и сообщение исключения, не скрывая его.
- Работать с любыми сигнатурами (*args, **kwargs).
- Сохранять метаданные функции (__name__, __doc__) через functools.wraps.

# Установка виртуального окружения и запуск
1. Клонируйте репозиторий

```
git clone <URL репозитория>
cd timed_logged
```

2. Создайте виртуальное окружение

```
python -m venv venv
```

3. Активируйте виртуальное окружение

* Windows CMD


```
.\venv\Scripts\activate
```

* Windows PowerShell


```
.\venv\Scripts\Activate.ps1
```

* macOS/Linux


```
source venv/bin/activate
```

После активации виртуального окружения в командной строке появится префикс venv.
4. Запустите программу

```
python task_3_timed_logged.py
```

Пример работы:

```
Функция: slow_sum, аргументы ((1, 2), {'delay': 0.2}), результат 3, время 200.76089999929536 мс
slow_sum
Складывает a и b.
```

Время выполнения от запуска к запуску немного отличается.

Если функция выбрасывает исключение, декоратор выводит его тип и сообщение и пробрасывает дальше:

```
Ошибка: TypeError : unsupported operand type(s) for +: 'int' and 'str'
```

Зависимости проекта
Внешних зависимостей нет — используются только модули стандартной библиотеки Python `time` и `functools`.
